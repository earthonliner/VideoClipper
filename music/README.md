# 本地曲库

把免费、可商用的背景音乐放进本目录（可以建子目录），然后让 Agent 运行 `music_scan` 收录并打情绪标签。

免费来源：
- YouTube Studio → 音频库（Audio Library）：选“无需署名”的曲目最省事
- Pixabay Music：https://pixabay.com/music/
- Free Music Archive：https://freemusicarchive.org/ （注意每首曲子的 CC 协议，避免 NC/ND）

`library.json` 记录每首曲子的情绪、时长、来源和授权信息。音频文件本身不提交进 git。
